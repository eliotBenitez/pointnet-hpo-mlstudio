# Боковой список документов Implementation Plan

> **For agentic workers:** Use executing-plans to implement and verify.

**Goal:** Упростить выбор документов в «Артефактах».

**Architecture:** В `mlstudio/src/main.rs` заменить ряд кнопок прокручиваемым списком слева, сгруппированным по каталогу прогона; справа сохранить просмотр документа и путь.

**Tech Stack:** Rust, GPUI.

**Spec:** `docs/superpowers/specs/2026-11-13-artifact-sidebar-design.md`

## Global Constraints

Русский интерфейс; существующие цвета и стили; не менять 3D-превью или содержимое файлов.

## Review Focus

- Пустой каталог: сводный отчёт и сообщение о недоступности остаются доступны.
- Прогон с одним документом: отображается только найденный документ.
- Большое число прогонов: список прокручивается независимо.
- Длинные имена: не вытесняют содержимое документа.
- Смена выбранного документа: отображаются его содержимое и путь.
