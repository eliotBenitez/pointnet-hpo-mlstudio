# Оформление вкладок артефактов

Цель: заменить кнопки «Документы» и «3D-превью модели» вкладками с подчёркиванием активной; добавить существующие иконки документа и базы данных к пунктам списка.

Изменить `mlstudio/src/main.rs`, сохраняя обработчики, группировку, русский текст, палитру и обе темы. Проверить `cargo test`, `cargo build --release`, обновить корневой exe; визуальную проверку отметить отдельно.
