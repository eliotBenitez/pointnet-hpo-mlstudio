# Сворачивание блока ресурсов — план реализации

> **Для исполнителя:** выполнять задачи последовательно; после каждого изменения запускать указанную проверку.

**Цель:** добавить сворачивание всего блока «РЕСУРСЫ» по клику на заголовок, сохранив строку проекта и темы видимой.

**Архитектура:** состояние `resources_collapsed: bool` хранится в `Studio` и живёт до пересоздания приложения. `render_usage` строит существующий блок, делает заголовок кнопкой и добавляет показатели только в раскрытом состоянии; мониторинг не затрагивается.

**Стек:** Rust, GPUI/gpui-component, существующий `mlstudio`.

**Спецификация:** `docs/superpowers/specs/2026-11-13-collapsible-resources-design.md`

## Глобальные ограничения

- UI и подписи остаются на русском языке.
- Не менять сбор показателей, формат значений и строки логов.
- Путь проекта и переключатель темы остаются видимыми.
- Не добавлять зависимости.

## Фокус проверки

- Первоначальное состояние раскрыто и полностью сохраняет текущий вид.
- Клик по заголовку скрывает и повторно показывает CPU, RAM, GPU и видеопамять.
- При отсутствии GPU заголовок всё равно работает, а сообщение «ГП: нет данных» скрывается вместе с блоком.
- Значения мониторинга продолжают обновляться при свернутом блоке.
- Состояние не записывается в `studio.json` и сбрасывается при пересоздании `Studio`.

### Задача 1: Состояние и рендер блока ресурсов

**Файлы:**
- Изменить: `mlstudio/src/main.rs` — структура `Studio`, конструктор `new`, метод `render_usage`.
- Проверка: `cargo test` и `cargo build --release` из `mlstudio/`.

**Шаги:**
- [ ] Добавить в `Studio` поле `resources_collapsed: bool` рядом с UI-состоянием.
- [ ] Инициализировать поле значением `false` в `Studio::new`.
- [ ] В `render_usage` сделать заголовок кликабельным через существующий GPUI `.on_click(cx.listener(...))`, переключая состояние и вызывая `cx.notify()`.
- [ ] Добавить визуальный индикатор `⌄` для раскрытого и `›` для свернутого состояния.
- [ ] Обернуть текущий рендер показателей в условие `!self.resources_collapsed`; при сворачивании скрывать также «ГП: нет данных».
- [ ] Не переносить строку проекта/темы и не менять мониторинг.
- [ ] Запустить `cargo test`; ожидать успешное завершение.
- [ ] Запустить `cargo build --release`; ожидать успешную сборку.
