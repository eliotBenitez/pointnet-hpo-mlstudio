# Боковой список сцен Implementation Plan

> **For agentic workers:** Use executing-plans to implement.

**Goal:** Упростить выбор сцен в 3D-превью.

**Architecture:** В `mlstudio/src/main.rs` заменить список кнопок сцен боковой панелью, построенной по `self.datasets`; сохранённый `Preview.scene` определяет выделение. Остальная панель использует существующий `render_preview`.

**Tech Stack:** Rust, GPUI.

**Spec:** `docs/superpowers/specs/2026-11-13-scene-sidebar-design.md`

## Global Constraints

Русский интерфейс; стиль `mlstudio/DESIGN.md`; не менять рендер облака, модели и инференс.

## Review Focus

- Несколько датасетов: каждая сцена доступна в своей группе.
- Много сцен: список прокручивается независимо от превью.
- Совпадающие имена сцен: выделение определяется полным путём.
- Нет сцен: выводится сообщение, превью не падает.
- Выбор нескольких сцен подряд: обновляется существующее превью.
