# Первый этап вкладки «Артефакты» — план реализации

> **Для агентных исполнителей:** использовать TDD; после каждой задачи запускать `cargo test`.

**Цель:** добавить в «Артефакты» навигацию первого этапа: «Сравнение», «Графики обучения» и «Логи», не дублируя существующую реализацию сравнения и графиков во вкладке «Прогоны».

**Архитектура:** `Studio` получает режим артефактов вместо двухпозиционного `artifact_3d`. Существующие `render_compare` и `f1_chart` переиспользуются через read-only оболочки. Для логов добавляется data-layer helper, который выбирает последний файл `<run>__*.log` в `mlstudio-logs`, после чего UI показывает список прогонов и содержимое файла без редактирования.

**Технологии:** Rust, GPUI/gpui-kit, stdlib `cargo test`, существующие `Run`, `Trial`, `LineChart`, `artifact_markdown`.

**Ограничения:** русский UI; не менять Python и формы логов; не выдумывать метрики; следовать `mlstudio/DESIGN.md`; не удалять незакоммиченные пользовательские изменения.

## Файлы

- Modify: `mlstudio/src/data.rs` — поиск и чтение сохранённых логов; unit-тесты.
- Modify: `mlstudio/src/main.rs` — состояние режима «Артефакты», вкладки и render-функции.
- Modify: `mlstudio/PRODUCT.md` — зафиксировать добавленные возможности.
