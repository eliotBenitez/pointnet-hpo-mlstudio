# Боковой список документов

Заменить переносимые кнопки документов в разделе «Артефакты» боковым списком: сводный отчёт сверху, затем прогоны с найденными пунктами «Отчёт» и «Данные». Активный документ выделяется. Список и содержимое прокручиваются независимо; путь и отображение Markdown сохраняются. 3D-превью не изменяется. Соблюдать существующий дизайн ML Studio и русский интерфейс.

Рассмотрены также два последовательных селектора и раскрывающиеся группы: они экономят место, но требуют дополнительных действий. Выбран боковой список для быстрого доступа.
