# Сворачивание ресурсов

## Цель
Освободить место в боковой панели ML Studio, позволяя скрыть показатели ресурсов.

## Подходы
- Сворачивать весь блок по заголовку — выбранный вариант: простое управление без лишних элементов.
- Сворачивать отдельные показатели — избыточно для небольшого блока.

## Поведение и ограничения
Заголовок «РЕСУРСЫ» с индикатором переключает видимость всех показателей. Изначально блок раскрыт; состояние действует в течение работы окна и не сохраняется на диск. Путь проекта и кнопка темы остаются видимыми. Сбор и отображаемые значения ресурсов не меняются. Использовать существующие компоненты GPUI и оформление ML Studio, без новых зависимостей.
