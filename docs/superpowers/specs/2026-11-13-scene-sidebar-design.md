# Боковой список сцен

В разделе «Артефакты → 3D-превью модели» заменить ряд кнопок сцен прокручиваемым списком слева. Сгруппировать сцены по датасетам, выделять выбранную по полному пути. Справа оставить существующее превью, выбор модели и управление камерой. Пустой список должен отображаться явно. Сохранить русский интерфейс и существующий стиль ML Studio.

Альтернатива — выпадающий список — экономит ширину, но усложняет частое переключение; выбран боковой список, согласованный с пользователем.
